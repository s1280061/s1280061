### About

自動運転・ADAS のための **解釈可能な安全推論** を研究するリサーチエンジニア。
現在は **自動車メーカー** にて先進運転支援に関わる知覚・予測の研究開発に従事。
知覚 → 軌道予測 → リスク評価 → ドライバーへの助言までを一貫してモデル化しています。

- 🔭 **Focus** — Risk-aware perception, trajectory prediction, V2X cooperative perception
- 🧠 **Interests** — Vision-Language Models (VLM) for driving, pedestrian intention, HCI / eHMI
- 🚗 **Flagship** — *RiSA: Risk-aware Situational Assistant* (IEEE BigData 2025)
